Перенос AimForge в Claude Code (вкладка Code в приложении Claude)
=================================================================

1. Дважды кликни setup.bat в этой папке.
   Он сам:
   - поставит Git, Python и Node.js, если их нет (через winget; может спросить разрешение Windows);
   - превратит эту папку в git-репозиторий github.com/kla1mmor/AimForge
     (при первом обращении откроется окно входа GitHub — войди как kla1mmor);
   - сохранит твои настройки, результаты, AimForge.exe и server\admin_token.txt;
   - скачает raylib, соберёт свежий AimForge.exe и положит его сюда.

2. Открой приложение Claude → вкладка Code (вверху боковой панели).
   Под полем ввода: окружение — Local, папка — Open folder… → C:\Files alikhan\vibecoding\AimForge

3. Первое сообщение новой сессии, например:
   «Прочитай CLAUDE.md и docs/USER_GUIDE.md. Проверь Alt+Tab в версии 1.2.1 на моём ПК
    и, если всё ок, выпусти релиз v1.2.1.»

Claude Code прочитает CLAUDE.md: там описаны сборка, сервер рейтинга, правила обновления
руководства и текущее состояние проекта.

Если setup.bat ругается — скопируй текст ошибки и вставь его в сессию Code: там Claude
может сам выполнить команды на твоём компьютере.
