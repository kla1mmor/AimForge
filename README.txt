AimForge 1.2 — тренажёр аима (Windows, отдельный .exe)
Полное руководство: USER_GUIDE.md (рядом с программой) или https://github.com/kla1mmor/AimForge/blob/main/docs/USER_GUIDE.md
====================================================

ЗАПУСК
  Просто запусти AimForge.exe. Установка не нужна, интернет не нужен.
  Рядом с программой создаются файлы:
    aimforge_settings.cfg   — настройки (мышь, прицел, цели, экран, звук)
    aimforge_scenarios.cfg  — твои изменения параметров сценариев
    aimforge_scores.csv     — история всех заходов (рекорды, графики)
    aimforge_pending.txt    — онлайн-результаты, которые ещё не удалось отправить
  Положи exe в папку, где есть право записи (например, Документы или Рабочий стол).

  Если Windows SmartScreen предупредит («Неизвестный издатель»):
  «Подробнее» → «Выполнить в любом случае». Файл не подписан сертификатом.

УПРАВЛЕНИЕ
  ЛКМ     — выстрел (в трекинге — держать)
  R       — перезапуск сценария
  Esc     — пауза / назад
  Пробел  — ещё раз на экране результата

ALT+TAB
  • При переключении (Alt+Tab, Win, клик по другому окну) игра сразу встаёт на паузу,
    курсор освобождается и остаётся там, где был, зажатая ЛКМ сбрасывается.
  • В фоне игра ограничивает себя ~30 FPS и не грузит видеокарту.
  • Режим «Полный экран» (эксклюзивный) при Alt+Tab сворачивается — так устроен Windows.
    Если хочешь, чтобы игра оставалась видна на втором мониторе и переключение было
    мгновенным — выбери режим «Без рамки» (задержка почти та же).
  • Клик, которым ты возвращаешься в окно, не нажимает кнопки меню.

ВВОД И ЗАДЕРЖКА
  • Мышь читается через Raw Input (WM_INPUT): сырые отсчёты сенсора, без ускорения
    Windows («Повышенная точность указателя» не влияет) и без системного курсора.
  • Каждое событие мыши применяется в порядке поступления: выстрел учитывает поворот,
    сделанный в том же кадре до клика (как при 1000–8000 Гц опросе).
  • VSync выключен всегда. Лимитер кадров ждёт ДО чтения ввода, поэтому кадр
    рисуется с самыми свежими данными мыши.
  • «Режим низкой задержки» (по умолчанию включён) — glFinish после кадра, драйвер
    не копит очередь кадров.
  • Поток игры регистрируется в MMCSS «Games», таймер Windows 1 мс, ожидание кадра —
    высокоточный таймер + доводка спином.
  • Для минимальной задержки: режим «Полный экран», родное разрешение, максимальная
    частота (например 2560×1440 @ 240 Гц), лимит FPS — «Без ограничения» или заметно
    выше частоты монитора.

ЧУВСТВИТЕЛЬНОСТЬ
  Настройки → Мышь: выбери профиль игры (Valorant / CS2·Apex·Source / Overwatch 2)
  и введи свою чувствительность и DPI — ощущения будут 1:1 с игрой. Можно задать
  напрямую в см/360. FOV ставь как в игре (Valorant 103°).
  Любое число можно ввести с клавиатуры: кликни по полю со значением, набери, Enter.

СЦЕНАРИИ
  Флики:      Широкие флики · Флик-тех (центр и обратно) · Точные флики · Хедлайн · Сайдбокс
  Рефлекс:    Reflex Box · Первая пуля · Тайминг клика
  Переводка:  Гридшот · Быстрая переводка · Свитч-трекинг · Экстрим-динамик
  Трекинг:    Плавный трекинг · Реактивный трекинг
  Свои:       Свой сценарий (полностью настраиваемый)
  У любого сценария кнопка «Параметры»: количество целей, радиус, дистанция, зона
  появления (ширина/высота/сдвиг, только по бокам), время жизни, сжатие, скорость,
  разброс, частота смены направления, прочность, задержка появления, одна попытка,
  режим (клик / трекинг), длительность. «Сбросить» возвращает стандарт.

  Программы — наборы сценариев подряд (разминка перед матчем, флики, микрокоррекция,
  переводка, плавность), по мотивам планов тренировок из гайда.

ОНЛАЙН-РЕЙТИНГ (бесплатно)
  • Раздел «Рейтинг»: таблица лучших результатов всех игроков по каждому сценарию,
    твоё место, кнопка «В браузере». На экране результата — «Мировой рейтинг #N из M».
  • Настройки → Онлайн: введи ник (уникальный). Адрес официального сервера уже вписан:
    https://aimforge-leaderboard.kla1mmor.workers.dev  (таблицы в браузере: .../web)
  • Свой отдельный сервер (по желанию): папка server, файл DEPLOY.txt.
  • В рейтинг идут только сценарии со стандартными параметрами и множителем размера
    целей 1.0. Изменённые сценарии и «Свой сценарий» — только локальный рекорд.
  • Нет интернета — результат сохранится в aimforge_pending.txt и отправится позже.
  • ID и ключ игрока хранятся в aimforge_settings.cfg — перенеси файл на новый ПК,
    чтобы сохранить ник и место в таблице.

СЧЁТ
  Клик: за каждое убийство 100 очков + бонус до 100 за скорость (чем быстрее после
  появления цели или прошлого убийства, тем больше), итог умножается на точность.
  Трекинг: 100 очков за каждую секунду на цели при зажатой ЛКМ.

СБОРКА ИЗ ИСХОДНИКОВ (необязательно)
  Нужны zig (https://ziglang.org) и исходники raylib 5.5.
  Скрипт build_windows.sh собирает статический AimForge.exe (без консоли).
  Тестовая Linux-сборка: build_linux_test.sh (запуск с --demo <папка> делает
  автоматический прогон всех сценариев ботом и снимает скриншоты).
