Онлайн-рейтинг AimForge — свой сервер бесплатно (Cloudflare Workers + D1)
==========================================================================

ОФИЦИАЛЬНЫЙ СЕРВЕР уже работает:  https://aimforge-leaderboard.kla1mmor.workers.dev
Его адрес вшит в официальную сборку игры — ничего разворачивать не нужно.
Эта инструкция — только если хочешь СВОЙ отдельный сервер (например, закрытый для своей компании).
После развёртывания своего сервера впиши его адрес в игре: Настройки → Онлайн.

Что это: маленькая программа-сервер (worker.js) и база данных (D1) в облаке Cloudflare.
Бесплатный тариф, банковская карта не нужна. Сервер не «засыпает» от простоя.
Лимиты бесплатного тарифа: 100 000 запросов в день, база до 5 ГБ, 5 млн чтений и
100 000 записей в день — для компании друзей и сотен активных игроков с запасом.
Один заход в игре = 1 запрос на отправку + запросы таблиц, когда открываешь «Рейтинг».

Развернуть нужно ОДИН раз. Потом просто раздаёшь адрес друзьям.


ВАРИАНТ А — автоматически (≈5 минут)
------------------------------------
1. Установи Node.js LTS: https://nodejs.org (обычная установка «Далее-Далее»).
2. Запусти deploy.bat из этой папки.
3. Откроется браузер: войди в Cloudflare или зарегистрируйся (бесплатно) и нажми «Allow».
4. Если спросят имя поддомена workers.dev — введи любое свободное (например, твой ник).
5. В конце скрипт напишет адрес вида
       https://aimforge-leaderboard.ИМЯ.workers.dev
   (он же сохранится в server_url.txt).
6. В игре: Настройки → Онлайн → «Адрес сервера» → вставь адрес (Ctrl+V) → Enter.
   Введи ник → «Проверить подключение». Готово.
7. Отправь адрес друзьям — все, кто его укажет, попадут в одну таблицу.
   Веб-страница рейтинга для всех: <адрес>/web


ВАРИАНТ Б — вручную через сайт, без Node.js (≈10 минут)
-------------------------------------------------------
1. https://dash.cloudflare.com → зарегистрируйся / войди.
2. Слева «Storage & Databases» → «D1 SQL Database» → «Create» → имя: aimforge → Create.
3. Открой базу → вкладка «Console» → вставь ВЕСЬ текст из schema.sql → «Execute».
4. Слева «Compute (Workers)» → «Workers & Pages» → «Create» → «Start with Hello World»
   → имя: aimforge-leaderboard → «Deploy».
5. «Edit code» → удали всё → вставь весь текст из worker.js → «Deploy».
6. Вкладка «Settings» → «Bindings» → «Add» → «D1 database»
   → Variable name: DB   (именно так, большими буквами) → база: aimforge → «Deploy/Save».
7. Адрес воркера (…workers.dev) показан на его странице — его и вставляешь в игру.
8. (Необязательно) Settings → «Variables and Secrets» → Add → тип Secret,
   имя ADMIN_TOKEN, значение — любой длинный пароль. Нужен для бана читеров.


АДМИНИСТРИРОВАНИЕ
-----------------
Проверка, что сервер жив:   открой <адрес>/health   → «ok aimforge 1»
Таблицы в браузере:          <адрес>/web
Забанить игрока (удалить все его результаты и запретить отправку), в cmd/PowerShell:
   curl -X POST <адрес>/admin/ban -H "Authorization: Bearer ТОКЕН" -d "name=НИК"
   (ТОКЕН — из admin_token.txt, если разворачивал скриптом)

Если выйдет новая версия игры с изменёнными параметрами сценария — для этого сценария
автоматически начнётся новая таблица (ключ таблицы = хэш стандартных параметров).


ЧЕСТНО ПРО ЗАЩИТУ ОТ ЧИТОВ
--------------------------
Игра — обычный exe у игрока, поэтому «идеальной» защиты нет ни у одного бесплатного
решения. Что есть:
 • ник закреплён за игроком секретным ключом (нельзя отправлять от чужого имени);
 • сервер проверяет правдоподобие: точность = попадания/выстрелы, счёт сходится с
   убийствами и точностью, не больше 12 убийств/с, реакция не быстрее 30 мс,
   длительность 10–300 с, трекинг ≤ 100 очков/с;
 • лимиты частоты: 1 отправка в 5 с на игрока, 40 за 10 минут с одного IP;
 • бан по нику (см. выше).
Для игры с друзьями этого достаточно.
