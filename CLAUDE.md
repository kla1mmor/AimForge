# AimForge — notes for Claude

Aim trainer for Windows (C + raylib 5.5, OpenGL 3.3) with a Cloudflare leaderboard. The owner speaks Russian — talk to them and write user-facing text in Russian.

## Rules for every change
- **Update `docs/USER_GUIDE.md` with every user-visible change**: the relevant section *and* the "История версий" entry. Bump the version in `src/main.c` (`APP_VER`), `src/online.c` (`APP_VER`), `res/aimforge.rc` (FILEVERSION/PRODUCTVERSION/strings), `res/aimforge.manifest` and the guide header.
- Keep `README.txt` (ships in the zip) consistent with the guide.
- Commit + push to `main`; tag `vX.Y` to publish a GitHub Release (CI builds the zip).
- Changing a scenario's default params changes its leaderboard key (`scenario_ruleset`) → that board starts fresh. Mention it in the guide.

## Build
- Windows exe (cross-compile, works on Windows/Linux/macOS): `sh build_windows.sh` → `build/win/AimForge.exe`. Needs Python 3 and zig (`pip install ziglang`). raylib is the submodule `deps/raylib` (tag 5.5): clone with `--recursive`.
- On Windows without sh: run the same zig commands from `build_windows.sh` in PowerShell (`python -m ziglang cc ...`).
- Fonts are embedded: `tools/embed_fonts.py` generates `src/fonts_data.c` from `assets/fonts/` (gitignored, generated by the build scripts).
- `server/server_url.txt` is baked into the exe as `AIMFORGE_DEFAULT_SERVER` (used when the player's server field is empty).
- Linux test build: `sh build_linux_test.sh` (needs X11/GL headers; `XINC=` for extra headers). Self-test: `./build/linux/aimforge --demo <dir>` plays every scenario with a bot and writes screenshots; with `DEMO_SERVER=<url> DEMO_NICK=<nick>` it also exercises the online flow. `--print-rulesets` prints leaderboard keys.

## Code map
- `src/main.c` — app loop (frame limiter before input poll, Alt+Tab/minimize handling), all UI pages, results screen, demo bot.
- `src/game.c` — scenario simulation, spawning, movement, hit detection (ray vs sphere), scoring.
- `src/scenario.c` — 15 default scenarios, param table (editor + save/load), playlists, stats CSV, ruleset hash.
- `src/platform_win.c` — Raw Input (WM_INPUT ring buffer), cursor clip/lock, QPC timer, waitable-timer sleep, MMCSS, UTF-8 paths, BCryptGenRandom.
- `src/net.c` — background HTTP thread (WinHTTP on Windows, curl CLI on Linux test builds).
- `src/online.c` — leaderboard client: submit, pending queue (`aimforge_pending.txt`), boards cache, rank summary.
- `src/ui.c` — immediate-mode UI widgets (sliders, numeric/text fields with UTF-8 + Ctrl+V).
- `server/worker.js` — Cloudflare Worker; plain-text TSV API (`/health /register /submit /top /summary /web /admin/ban`); plausibility checks + rate limits. `server/schema.sql` — D1 schema.
